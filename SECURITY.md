# Security policy

Fulmen projects follow the [3 Leaps security reporting policy](https://github.com/3leaps/oss-policies/blob/main/SECURITY.md).
A project's own security policy provides any project-specific scope and
supported-version information.

**Do not report suspected vulnerabilities in public issues or pull requests.**
Email **security@3leaps.net**, or use the affected repository's private
vulnerability reporting feature when enabled.

Include the project and version, a description of the issue and its potential
impact, and the information needed to reproduce it safely. Do not send
credentials or unrelated private data. The upstream policy provides encryption
instructions and the disclosure process.
