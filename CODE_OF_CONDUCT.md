# Code of Conduct

Fulmen communities follow the [3 Leaps Code of Conduct](https://github.com/3leaps/oss-policies/blob/main/CODE-OF-CONDUCT.md).
It defines our participation standards, scope, and enforcement process.

Be respectful and constructive. Harassment, discrimination, and disclosure of
others' private information are not acceptable.

Report conduct concerns to **legal@3leaps.net**, as directed by the governing
Code of Conduct. Please use that private reporting route rather than a public issue.
