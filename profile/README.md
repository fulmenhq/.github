# Fulmen

**Start fast. Thrive on scale.**

Fulmen is the developer-experience toolbox for polyglot teams: language
foundations, forge templates, quality tools, and shared standards. This GitHub
organization, [`fulmenhq`](https://github.com/fulmenhq), publishes those
projects. Each repository keeps its own name. The org is the publisher.

This org is not [Lanyte](https://github.com/lanytehq) (the agent platform) and
not the [`3leaps`](https://github.com/3leaps) collection of independent
libraries, tools, and apps.

## Explore the projects

Language foundations (`*fulmen`) embed shared catalogs so Go, Python, Rust, and
TypeScript services use the same codes and schemas. Forge templates (`forge-*`)
are starters you clone and refit into your own backend or CLI. Tools are
unsuffixed CLIs and utilities. Standards live in Crucible.

### Language foundations

| Project | What it does |
| --- | --- |
| [gofulmen](https://github.com/fulmenhq/gofulmen) | Go catalogs and DX primitives—exit codes, schemas, config, and identity—derived from Crucible. |
| [pyfulmen](https://github.com/fulmenhq/pyfulmen) | The same catalogs and helpers for Python services. |
| [rsfulmen](https://github.com/fulmenhq/rsfulmen) | The same catalogs and helpers for Rust, selectable with crate feature flags. |
| [tsfulmen](https://github.com/fulmenhq/tsfulmen) | The same catalogs and helpers for TypeScript and Node, including compile-safe embedded assets. |

### Forge templates

| Project | What it does |
| --- | --- |
| [forge-workhorse-groningen](https://github.com/fulmenhq/forge-workhorse-groningen) | Go workhorse template for HTTP backends and CLIs. |
| [forge-workhorse-tuvan](https://github.com/fulmenhq/forge-workhorse-tuvan) | TypeScript workhorse template for HTTP backends and CLIs. |
| [forge-workhorse-roan](https://github.com/fulmenhq/forge-workhorse-roan) | Rust workhorse template for HTTP backends and CLIs. |

### Tools

| Project | What it does |
| --- | --- |
| [goneat](https://github.com/fulmenhq/goneat) | One CLI to orchestrate lint, format, and related quality checks across polyglot repos. |
| [refbolt](https://github.com/fulmenhq/refbolt) | Archives provider documentation into date-versioned Markdown trees. |
| [limensafe](https://github.com/fulmenhq/limensafe) | Local scanner for confidential context leakage in code, docs, and git surfaces. |
| [dimlox](https://github.com/fulmenhq/dimlox) | Moves, inspects, and splits large files across cloud object storage without loading them into memory. |
| [sumpter](https://github.com/fulmenhq/sumpter) | Recipe-driven extraction from XML, JSON, and NDJSON for structured pipelines. |
| [brooklyn-mcp](https://github.com/fulmenhq/brooklyn-mcp) | MCP server for browser automation, and a reference forge for other MCP servers. |

### Standards

| Project | What it does |
| --- | --- |
| [crucible](https://github.com/fulmenhq/crucible) | Schemas, standards, and templates consumed by the language libraries and forges. |

Install many of the CLIs from the [Homebrew tap](https://github.com/fulmenhq/homebrew-tap)
or the [Scoop bucket](https://github.com/fulmenhq/scoop-bucket). Container images
for CI and local tool runs live in [fulmen-toolbox](https://github.com/fulmenhq/fulmen-toolbox).

Projects are at different stages of development. Each repository's README and
release notes describe its current capabilities, maturity, and setup. For a
hands-on starting point, see [goneat](https://github.com/fulmenhq/goneat).
