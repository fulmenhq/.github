# Getting help

For a Fulmen project, start with its README, getting-started documentation,
release notes, and existing issues. If you still need help, open a question in
that project's issue tracker, following any project-specific support guidance.
Include the version, relevant environment, what you tried, and sanitized output.
Community support is best effort.

Use [this repository's issues](https://github.com/fulmenhq/.github/issues) for
organization-profile or shared-template problems, rather than product bugs.

For suspected vulnerabilities, follow the
[security policy](https://github.com/fulmenhq/.github/blob/main/SECURITY.md).
For conduct concerns, follow the reporting instructions in the
[3 Leaps Code of Conduct](https://github.com/3leaps/oss-policies/blob/main/CODE-OF-CONDUCT.md).

For policy questions and commercial inquiries, see
[3 Leaps support](https://github.com/3leaps/oss-policies/blob/main/SUPPORT.md).
